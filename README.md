## 🌟 What is featherwall?

featherwall is a tiny, powerful live-wallpaper engine built specifically for Windows 10 and Windows 11. It lets you set videos and images as your desktop background, adds a beautiful designed clock widget, and does it all in a single lightweight process.

No browser engine. No bloat. No dozens of background tasks eating your RAM. Just one small program that gets the job done.

It's perfect for people who want a dynamic, beautiful desktop without sacrificing performance.

## 👨‍💻 How to Use featherwall

### First Launch

When you first run featherwall, it will appear in your system tray (the little arrow near the clock in the bottom-right corner of your screen). That means it's working.

### Setting a Video Wallpaper

1. Right-click the featherwall icon in the system tray.
2. Select **"Set Video Wallpaper"**.
3. Browse to your video file (`.mp4`, `.mov`, `.avi`, `.wmv` etc.) and select it.
4. Featherwall will immediately set it as your desktop background.

### Setting an Image Wallpaper

1. Right-click the featherwall icon.
2. Select **"Set Image Wallpaper"**.
3. Choose your image file (`.jpg`, `.png`, `.bmp`, `.webp` etc.).
4. Done. Your new wallpaper is live.

### Using the Clock Widget

The clock widget is enabled by default. To customize it:

1. Right-click the featherwall icon.
2. Select **"Clock Settings"**.
3. You can change the font size, color, position, and whether it shows the date.
4. Toggle it on or off at any time.

### Pausing and Resuming

If you're gaming or watching a movie and want to save resources, just right-click the tray icon and choose **"Pause"**. Select **"Resume"** to bring it back.

## 🛠️ Troubleshooting

### Wallpaper Not Showing?
- Make sure you selected a valid video/image file.
- Try a common format like `.mp4` or `.jpg`.
- Restart featherwall from the system tray.

### The Video Is Stuttering?
- Use a lower resolution video (like 720p) for better performance.
- Check that you're not running other heavy programs at the same time.
- Update your graphics drivers.

### Featherwall Doesn't Start at Windows Boot?
- Open featherwall settings and enable **"Start with Windows"**.
- Make sure your antivirus isn't blocking it.

### Icons Are Hard to Read?
- Switch to a darker wallpaper image.
- Adjust your Windows icon text color or use desktop icon labels with a shadow.
